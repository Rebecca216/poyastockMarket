# 寶雅 (5904) 股市即時低價觀察與智慧通知系統

專為**寶雅 (5904.TWO / 上櫃)** 量身打造的即時行情監控與低價通知系統。支援網頁互動儀表板與 Python 背景獨立監控，提供極速 1 秒行情更新、五檔買賣價量、分時走勢圖及自訂低價推播音效與醒目彈窗。

---

## 🌟 核心特色

1. **⚡ 1 秒極速行情更新**：即時輪詢抓取成交價、漲跌、買賣五檔、當日高低點與成交量。
2. **🎯 自訂低價觸發門檻**：自由輸入目標價格（支援快捷按鈕 `-0.5元`、`-1.0元`、`-2%`、`設為現價`）。
3. **🔔 多重智慧通知管道**：
   - **桌面通知 (Web Notification)**：在背景作業時仍能彈出系統提醒。
   - **全螢幕醒目警示彈窗 (Alarm Modal)**：直接於畫面中央呈現警示標籤。
   - **自體合成警示音效 (Audio Chime)**：三音階悅耳提示聲，不依賴外部音檔。
   - **Windows 原生系統推播 + 蜂鳴器 (Python 背景監控)**。
4. **⚖️ 即時最佳五檔 (Order Book)**：清晰呈現買一~買五與賣一~賣五的價量深度與合計張數。
5. **📊 分時走勢圖 (Canvas)**：動態走勢與黃色低價警戒線對照。
6. **📱 全方位 RWD 響應式設計**：完美適配手機、平板與電腦螢幕。
7. **☀️/🌙 白天與深色主題切換**：白天模式文字超高對比，絕無文字模糊或看不清問題。

## 🚀 快速啟動方式

### 方法一：網頁互動儀表板（最推薦）
雙擊執行資料夾內的 **`啟動網頁即時監控.bat`**，或直接以瀏覽器開啟 **`index.html`**。

### 方法二：Python 背景終端監控
雙擊執行 **`啟動Python背景監控.bat`**，或在終端機執行：
```bash
py monitor.py
```
