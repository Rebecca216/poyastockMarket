# 🛒 寶雅 (5904) 股市即時低價觀察與智慧通知系統

專為觀察 **寶雅 (5904.TWO)** 所打造的即時股市行情監控與低價智慧警示系統。

---

## 🌟 核心功能特色

1. **即時行情與最佳五檔買賣盤 (Order Book)**：
   - 包含成交價、漲跌幅、今日最高/最低、開盤價、昨收價、成交量與成交金額。
   - 提供即時「買一至買五」與「賣一至賣五」價量深度可視化進度條。
2. **自訂低價通知門檻 (Custom Low Price Alert)**：
   - 使用者可**自由輸入目標低價**（例如：`74.0`、`73.5` 元）或使用快捷鍵（-0.5元、-1.0元、-2%、現價）。
   - 支援多種判斷邏輯：
     - **當成交價或委賣價 Ask ≤ 設定價格**（最推薦，當出現低價賣單時即可立刻買入）。
     - 當成交價 ≤ 設定價格。
     - 當委賣價 Ask ≤ 設定價格。
     - 當委買價 Bid ≤ 設定價格。
     - 當五檔內任一買賣價符合設定價格。
3. **多管道醒目警示提醒 (Multi-Channel Alerts)**：
   - 🔔 **瀏覽器桌面推播通知**：即使最小化或切換分頁，系統仍會彈出 Windows 桌面通知。
   - 🔊 **水晶和弦提示音 (Web Audio API)**：純程式合成優雅提醒音效，無須下載任何音效檔。
   - 🚨 **全螢幕醒目警示彈窗 (Alarm Modal)**：大字顯示觸發價格與警示原因。
   - ⏱️ **防洗版提醒冷卻機制**：可自訂每 1 分鐘、3 分鐘或 5 分鐘提醒一次。
   - 🧪 **一鍵模擬測試通知**：隨時點擊按鈕預覽推播、音效與彈窗。
4. **盤中走勢圖與警戒線 (Interactive Chart)**：
   - 動態分時價格走勢圖，並以黃色虛線直觀標示目前設定的「低價警戒線」。
5. **雙模式運行支援**：
   - 🌐 **網頁儀表板模式 (`index.html`)**：免伺服器，雙擊即可在瀏覽器中流暢運行。
   - 🐍 **Python 背景監控模式 (`monitor.py`)**：可在終端機背景運行，支援 Windows 原生系統推播與蜂鳴音效。

## 🚀 快速啟動方式

### 方法一：開啟網頁儀表板（推薦，視覺化最完整）
1. 雙擊執行 [`啟動網頁即時監控.bat`](啟動網頁即時監控.bat) 或直接開啟 [`index.html`](index.html)。
2. 進入頁面後：
   - 點擊右上角 **「啟用桌面推播」** 授權通知權限。
   - 在右側面板輸入您的 **「低價觸發門檻」**（例如：74.0 元）。
   - 點擊 **「儲存設定並同步監控」** 即可開始自動監控！
   - 您也可以點擊 **「🔔 立即模擬測試通知音效與彈窗」** 確認通知與聲音是否正常。

### 方法二：執行 Python 背景終端監控
1. 雙擊執行 [`啟動Python背景監控.bat`](啟動Python背景監控.bat) 或在終端機輸入：
   ```powershell
   py monitor.py
   ```
2. 預設參數可在 [`config.json`](config.json) 中直接調整：
   ```json
   {
     "stock_code": "5904.TWO",
     "target_low_price": 74.0,
     "condition": "price_or_ask",
     "check_interval_seconds": 1,
     "cooldown_seconds": 180,
     "enable_sound_beep": true,
     "enable_windows_toast": true
   }
   ```

## 📂 檔案架構說明

- [`index.html`](index.html) - 網頁版主頁面（包含五檔價量、分時走勢與低價設定面版）
- [`style.css`](style.css) - 深色高質感金融儀表板 CSS 樣式表
- [`app.js`](app.js) - 即時行情抓取、五檔深度渲染、Web Audio 音效與低價判斷引擎
- [`monitor.py`](monitor.py) - Python 版終端即時監控與 Windows 原生通知腳本
- [`config.json`](config.json) - Python 監控設定檔
- [`啟動網頁即時監控.bat`](啟動網頁即時監控.bat) - 一鍵啟動網頁監控
- [`啟動Python背景監控.bat`](啟動Python背景監控.bat) - 一鍵啟動 Python 監控
